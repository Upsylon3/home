# Design

Home should feel like one product rather than a collection of unrelated
self-hosted tools.

## Principles

- Clear before decorative.
- Consistent spacing, typography and controls.
- Light and dark themes are first-class.
- Mobile layouts should be designed for touch.
- Shared components should feel like part of the same ecosystem.

Prefer readable hierarchy, obvious primary actions and useful loading/error/
empty states. Avoid decoration that makes common tasks harder.

Existing assets in `design/` are the source material for application icons.
New apps should follow the existing visual language rather than inventing an
unrelated style.
