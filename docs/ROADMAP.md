# Roadmap

No fixed release schedule. This is a short list of direction.

## Near term

- Finish the HomeSync Android client.
- Continue extracting shared HomeCore functionality.
- Improve cross-application permission enforcement.
- Improve TLS/remote-access deployment.
- Stabilize HomeNotes.

## Later

- HomeTasks
- HomeMonitor
- HomeVault
- HomeAI
- HomeBridge

New applications should reuse shared platform capabilities rather than
duplicating identity, storage or other infrastructure.
