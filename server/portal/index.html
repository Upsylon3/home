    Add a HOME

    At home, you can use a local address such as http://192.168.1.50:8080. Outside, use the HTTPS address set up on your server. Saving an address does not make it reachable.

    Need to set up a server?

    Get the HOME server download and follow its START-HERE guide. Installation creates your first account locally. To join someone else's HOME, ask its owner for its address and an account setup code.

    Enter passwords and setup codes only on your own server. This portal has no central HOME login or account directory. Multiple saved addresses are shortcuts; shared accounts across servers are not implemented yet.

    Clear an entry with Forget. Clearing browser storage removes every saved address here, but leaves accounts and data on your servers. GitHub hosts this page and may log visits.
